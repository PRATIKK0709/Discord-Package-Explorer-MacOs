# DSP

A native macOS app for exploring a Discord data package locally.

[Watch the demo](media/DSP-demo.mov)

## Features

- Message, server, and direct-message activity
- Account, profile, payment, application, and support-ticket history
- Hourly, weekly, and yearly usage summaries
- Local processing with no uploads

## Run

Open `DiscSwiftPckg.xcodeproj` in Xcode and press `⌘R`.

Choose `demo-package` to explore the app without using a personal data export.

DSP is an independent project and is not affiliated with Discord.
